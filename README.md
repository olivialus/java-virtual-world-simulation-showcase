# Virtual World Simulation with A* Pathfinding

A quarter-long Java project completed in a two-person team at Cal Poly. We extended a course-provided virtual-world framework by implementing pathfinding, event-driven behaviors, and new interactive entities.

## Features

- Implemented A* pathfinding using a Manhattan-distance heuristic
- Added obstacle-aware navigation for moving entities
- Added dragons that dynamically spawn and move through the world
- Added eggs that hatch into new dragons
- Added lava generation and new environmental interactions
- Extended and modified an existing object-oriented Java codebase
- Worked with event-driven behaviors and scheduled actions

## Technologies

- Java
- Object-Oriented Programming
- A* Search
- Data Structures and Algorithms
- Git / GitHub

## Project Context

This was a quarter-long two-person course project at Cal Poly. We extended a course-provided Java virtual-world framework by implementing A* pathfinding, event-driven behaviors, and new interactive entities.
